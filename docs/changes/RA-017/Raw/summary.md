Bạn là AI engineer trong dự án “AI Smart Resource Allocation & Bench Prediction System”.

Hãy phát triển tính năng Add Engineer cho hệ thống:

1. Ở màn hình engineers, hiện đã có nút Add Engineer nhưng chưa hoạt động. Khi nhấn nút này, hãy hiển thị một Modal cho phép người dùng nhập thông tin để thêm engineer mới.
2. Các trường thông tin cần nhập trong Modal giống với cấu trúc đã dùng cho import CSV engineer (ví dụ: name, email, level, start_date, ...)., về Modal hiển thị có thể tham khảo Modal AI-Smart-Resource-Allocation/apps/web/features/allocation/ConfirmAllocationModal.tsx
3. Tạo API backend để thêm engineer mới vào hệ thống.
4. Kết nối frontend với API này: khi người dùng nhập đủ thông tin và nhấn xác nhận trên Modal, gửi request lên backend để tạo engineer mới, sau đó cập nhật lại danh sách.
5. Giải thích rõ các file cần sửa/viết mới ở cả frontend và backend, và trình bày các bước thực hiện.
